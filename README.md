# PizzaExpress
Sistema de Gestión de Pedidos e Inventario para una pizzería, desarrollado como continuación del proyecto académico de Ingeniería de Software.

Descripción del proyecto
PizzaExpress es una propuesta de solución orientada a facilitar la gestión de los principales procesos de una pizzería.
El proyecto contempla funcionalidades para:
•	Inicio de sesión.
•	Gestión de usuarios y roles.
•	Registro y gestión de pedidos.
•	Gestión y actualización del inventario.
•	Descuento automático de ingredientes.
•	Alertas de inventario.
•	Validación de entregas.
•	Consulta de reportes de ventas.

Alcance del MVP
El proyecto contempla inicialmente los procesos principales de pedidos e inventario.
Las siguientes funcionalidades quedan planteadas como posibles mejoras futuras:
•	Pagos en línea.
•	Seguimiento de domicilios mediante GPS.
•	Programa de fidelización.
•	Aplicación móvil.
•	Notificaciones automáticas.
