Evidencias de Pruebas – PizzaExpress
1. Introducción

Esta carpeta contiene la documentación de las evidencias asociadas al Plan de Pruebas del sistema PizzaExpress.

Las evidencias presentadas en este proyecto tienen carácter académico y simulado, de acuerdo con el alcance definido para la actividad.

Su objetivo es representar los resultados esperados de las pruebas realizadas sobre las principales funcionalidades propuestas para el sistema.

2. Evidencias contempladas

Las evidencias se organizan de acuerdo con los casos de prueba definidos en el Plan de Pruebas.

Código	Funcionalidad	Evidencia
CP-01	Inicio de sesión exitosa	Acceso correcto al sistema
CP-02	Inicio de sesión con datos incorrectos	Mensaje de credenciales inválidas
CP-03	Gestión de usuarios y roles	Registro y modificación de usuarios
CP-04	Registro de pedidos	Pedido registrado correctamente
CP-05	Actualización automática del inventario	Inventario antes y después del pedido
CP-06	Alerta de inventario	Notificación de nivel bajo
CP-07	Validación de entrega	Entrega validada correctamente
CP-08	Reporte de ventas	Reporte generado
CP-09	Restricción por roles	Acceso denegado a función no autorizada
CP-10	Prueba de estrés	Comportamiento esperado ante múltiples solicitudes
3. Resultado general

De acuerdo con las pruebas simuladas definidas en el Plan de Pruebas:

Casos de prueba ejecutados: 10
Casos aprobados: 10
Casos no aprobados: 0
Porcentaje simulado de aprobación: 100 %

Los resultados indican que las funcionalidades evaluadas cumplen con los criterios de aceptación establecidos para esta actividad académica.

4. Consideración sobre las evidencias

Las evidencias simuladas no contienen información personal, credenciales reales ni datos sensibles.

Su finalidad es demostrar la forma en que se documentaría el resultado de las pruebas dentro de un proceso de Ingeniería de Software.

En una implementación real, estas evidencias serán reemplazadas o complementadas con:

Capturas de pantalla.
Registros del sistema.
Informes de ejecución.
Otros elementos verificables.
5. Conclusión

La documentación de evidencias permite mantener trazabilidad entre los casos de prueba definidos y los resultados obtenidos.

La organización de estas evidencias facilita la revisión del proyecto y permite demostrar el cumplimiento de los criterios establecidos para las funcionalidades principales de PizzaExpress.
